# Portfolio Website

A static portfolio website with a dark galaxy theme that can be deployed to GitHub Pages.

## Features

- Responsive design that works on all devices
- Dark theme with galaxy colors
- Project carousels for showcasing work
- Contact form (demo only, not functional without backend)
- Smooth scrolling and animations

## Deployment to GitHub Pages

1. Create a new repository on GitHub
2. Clone this repository to your local machine
3. Push the code to your GitHub repository
4. Go to your repository settings on GitHub
5. Scroll down to the GitHub Pages section
6. Select the branch you want to deploy (usually `main` or `master`)
7. Select the root folder as the source
8. Click Save
9. Your site will be published at `https://yourusername.github.io/repositoryname/`

## Customization

- Update the content in `index.html` with your personal information
- Replace the profile image with your own
- Add or remove projects in the carousel sections
- Modify the colors in `css/styles.css` to match your preferences

## Structure

- `index.html` - Main HTML file
- `css/` - CSS stylesheets
  - `styles.css` - Main styles
  - `carousel.css` - Styles for the project carousels
- `js/` - JavaScript files
  - `script.js` - Main script file
  - `carousel.js` - Script for the project carousels
